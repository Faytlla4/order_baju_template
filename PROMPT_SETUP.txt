Saya butuh bantuan diagnosa dan perbaikan project CI3 + Bonfire di Windows (Laragon) dengan PostgreSQL.

## Info Project
- Repo: https://github.com/Faytlla4/order_baju_template.git (branch main)
- Stack: CodeIgniter 3 + Bonfire 0.9.0-dev HMVC + PostgreSQL 18.4 + PHP 7.4 + AdminLTE
- Domain: apktemplate.test
- Database sudah di-import dari backup server asli

## Yang Sudah Benar
- Website bisa dibuka di http://apktemplate.test/admin
- Login admin / password bisa
- Beberapa fitur sudah sesuai setelah git pull

## Masalah yang Perlu Diperbaiki

### 1. Tampilan tidak berubah
Beberapa halaman masih menampilkan tampilan LAMA (sebelum pull). Kemungkinan:
- File view yang di-cache oleh browser
- File CSS/JS yang di-cache
- Asset tidak ke-deploy dengan benar

### 2. Fitur yang error
Ada beberapa halaman yang muncul error. Tolong cek error log di:
- `application/logs/` (lihat file log terbaru)
- Browser console (F12 > Console)
- Apache error log di Laragon

### 3. Module yang perlu dicek
Pastikan semua module ini bisa diakses dan berfungsi dari sidebar:
- **Content** → Order Baju (CRUD + upload dokumen) di admin/content
- **Master** → Jenis Baju, Ukuran, Warna (CRUD dengan tombol Create/Edit) di admin/master
- **Transaksi** → Daftar Transaksi (CRUD + dokumen) di admin/transaksi
- **Laporan** → Cetak Laporan PDF + Excel di admin/reports
- **Backup** → Backup Dokumen + Backup Database di admin/backup

## Yang Perlu Dilakukan

1. **Clear browser cache** teman saya (Ctrl+Shift+Delete > Clear all)
2. **Restart Apache & PostgreSQL** di Laragon
3. Cek error log di `application/logs/` — kasih tau saya isi errornya
4. Cek setiap module satu per satu di sidebar, kasih tau mana yang:
   - ✅ Sudah benar
   - ❌ Masih tampilan lama
   - ❌ Error (screenshot atau copy error message)
5. Kalau ada error "permission denied" atau "access restricted", berarti permissions di database belum lengkap. Jalankan migration:
   ```
   php index.php tools migrate
   ```
6. Kalau tampilan tidak berubah, coba hard refresh: **Ctrl+Shift+R** atau buka di incognito window
7. Pastikan semua file sudah ter-update dengan cek isi file yang dicurigai, contoh:
   ```
   type application\modules\master_jenis_baju\views\master\_sub_nav.php
   ```

Kasih tau saya hasil pemeriksaan di atas supaya saya bisa bantu perbaiki tepat sasaran.
